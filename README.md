# Self-Supervised Representation Learning for Explainable Papaya Leaf Disease Segmentation

Repository for the capstone research project, including training notebooks, experimental reports, pipeline diagrams, model architectures, dataset versions, checkpoints, evaluation results, and reusable source code.

## Repository structure

| Directory | Contents |
| --- | --- |
| `01_Notebooks/` | Kaggle/Jupyter notebooks for preprocessing, SSL, training, and evaluation |
| `02_Reports/` | YOLO26, DeepLabV3, SegFormer, and final reports |
| `03_Diagrams/` | Pipeline and workflow diagrams |
| `04_Model_Architectures/` | Architecture diagrams and configurations |
| `05_Datasets/` | Original, balanced, semantic, and split datasets |
| `06_Saved_Models/` | Trained model checkpoints and SSL weights |
| `07_Results/` | Performance metrics, plots, tables, and predictions |
| `08_Source_Code/` | Scripts for preprocessing, training, and evaluation |

## Before uploading large files

GitHub's web upload has file-size and file-count limits. For large datasets and model checkpoints, use Git LFS with GitHub Desktop/Git or reference an externally hosted, versioned dataset/model artifact. Do not put private, restricted, or unlicensed data in a public repository.

## Reproducibility checklist

- [ ] Include final notebooks and code used for each run
- [ ] Document dataset sources, licenses, preparation, and train/validation/test splits
- [ ] Record experiment configurations, hyperparameters, epochs, seeds, and dependency versions
- [ ] Include evaluation tables, figures, and class mappings
- [ ] Describe how to load/download trained checkpoints
- [ ] Document inference or reproduction commands

_Note: The `.gitkeep` files are placeholders, so Git can track otherwise empty directories. Delete a placeholder after adding real files if desired._
